# /run-all

themes/ 配下の alpha / beta / gamma / delta を束ねて実行する。

## 手順

1. 抽出（並列）
   - Taskツールで4テーマの抽出フェーズを同時起動する
   - 各テーマへ渡すのは `themes/<theme>/` のパスだけ。他テーマの情報は渡さない
   - 各テーマは `themes/<theme>/out/result.json` を書く

2. 集約（逐次）
   - 4つの result.json を読み、共通スキーマへ正規化する
   - 読めない／壊れているテーマは status=failed として記録し、止めない

3. 分類・突合（並列）
   - 正規化済みデータを分類エージェントと突合エージェントで並列処理する
   - 2系統は互いの出力を入力にしない

4. 永続化（逐次）
   - sqlite MCP へ runs / theme_results / items を書き込む

## 終了時
Stop フックが失敗テーマ数と総件数を要約する。サマリだけを最終出力にする（中間ログは出さない）。

## 失敗時の挙動
- 1テーマ失敗 → そのテーマのみ skip、全体は継続
- リトライは各テーマ最大1回
