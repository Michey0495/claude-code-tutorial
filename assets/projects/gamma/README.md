# T3 提案QAビルダー

RFPと顧客ヒアリングから、審査委員の想定質問と根拠つき回答案を組み立てます。最終成果物はカテゴリ別の想定問答集（静的ページまたはMarkdown）。

すべてローカルで完結します。外部送信はありません。企業名はすべて架空です。

## 前提

- Claude Code が使えること
- 学んでおく章: CLAUDE.md / Skills / Subagents / Writer-Reviewer / 並列化戦略

## 同梱物

```
gamma/
├── README.md                 この手順書
├── CLAUDE.md                 回答トーンと出典の付け方
├── client-brief.md           依頼背景（架空）
├── rfp-excerpt.md            RFP抜粋
├── hearing.md                顧客ヒアリングメモ
└── .claude/skills/qa-builder/SKILL.md   QA生成スキル
```

## 進め方

1. 一式を展開し、`CLAUDE.md` で回答トーンと出典ルールを確認する
2. `rfp-excerpt.md` と `hearing.md` を別エージェントで同時に要約する（並列フェーズ）。資料種別ごとに文脈を分ける
3. 要約から論点を抽出し、審査側の想定質問を起こす（逐次フェーズ）
4. 各質問に回答案と出典（RFP/ヒアリングの該当箇所）を付ける
5. カテゴリ別に整形し、Reviewer役で回答どうしの矛盾を洗う

## 受入基準

- 想定QAが20問以上ある
- 各回答に出典が付いている
- カテゴリで分類されている
- 回答どうしに矛盾がない
- 目的の質問を探しやすい体裁になっている

## 比較の観点

質問の網羅性 / 回答の具体性 / 出典の妥当性 / 一貫性。
