---
name: qa-builder
description: 要約と原資料から想定質問・回答案・出典を組み立てる。
---

# 入力
- RFP抜粋とヒアリングの要約（並列フェーズの成果）
- 原資料 rfp-excerpt.md / hearing.md（出典の引用元）

# 手順
1. 要約から論点を抽出する（評価の観点、制約、懸念事項を優先）
2. 各論点に対し、審査委員が突いてきそうな質問を起こす
3. 各質問に回答案を書く。結論先出し、提案内容に即した具体
4. 回答末尾に出典を付ける: `根拠: <資料名> / <引用 20〜40字>`
5. カテゴリを付ける: 体制 / スケジュール / 費用 / 技術 / 運用保守 / 実績

# 出力
qa(id, category, question, answer, source, confidence) のリスト。20問以上。

# 制約
- 資料にない内容を回答にしない。想定が必要な箇所は confidence=低 と明記
- 数値や前提は資料の値に合わせる。回答間で食い違わせない
- 1質問1論点。複合質問は分割する
