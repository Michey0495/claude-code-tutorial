# T4 コンプライアンス監査自動化

社内規程と過去判例に照らして、提出された成果物の違反箇所を根拠つきで検出し、監査レポートにまとめます。最終成果物は監査レポート生成システム。

すべてローカルで完結します。外部送信はありません。組織名はすべて架空です。

## 前提

- Claude Code が使えること
- 学んでおく章: CLAUDE.md / Skills / Subagents / MCP / Hooks

## 同梱物

```
delta/
├── README.md                 この手順書
├── CLAUDE.md                 重大度の定義とレポート様式
├── client-brief.md           依頼背景（架空）
├── rules.md                  社内規程
├── deliverable-sample.md     監査対象の成果物サンプル
├── precedents.md             過去判例
└── .claude/agents/audit-checker.md   監査サブエージェント
```

## 進め方

1. 一式を展開し、`CLAUDE.md` で重大度の定義とレポート様式を確認する
2. `rules.md` と `precedents.md` をMCP(filesystem)で読み込みインデックス化する（逐次フェーズ）
3. `deliverable-sample.md` を章単位で分け、`audit-checker` を並列起動する（並列フェーズ）。各エージェントは担当章と規程インデックスだけを持つ
4. 違反候補を重大度で集約し、過去判例と突き合わせる
5. 指摘・根拠条文・是正案の監査レポートを生成する。PostToolUseフックで体裁を検証する

## 受入基準

- 規程の全項目を成果物と照合できている
- 違反に根拠条文が紐づいている
- 重大度が判定されている
- 是正案が具体的に示されている
- 同じ入力で再現できる

## 比較の観点

検出網羅性 / 誤検知率 / 根拠の正確性 / 是正案の実用性。
