# 議事録ToDo自動抽出 - プロジェクト規約

## 目的
会議メモから実行可能なToDoだけを抜き出し、担当・期限・優先度つきの台帳にする。

## ToDoの定義
「誰かが何かをやる」と読める行動。決定事項や感想は対象外。期限が明示されていなくてもToDoになりうる。

## 台帳スキーマ
todos(id, task, owner, due, priority, source_meeting, source_quote, status)

- owner: 発言から特定できる担当者名。不明なら "未割当"
- due: ISO形式。明示なしは会議日＋既定オフセット（高=3日 / 中=7日 / 低=14日）
- priority: 高 / 中 / 低
- status: 既定は "未着手"

## 優先度の基準
- 高: 他作業の前提になる、または期限が会議日から1週間以内
- 中: 通常の対応事項
- 低: あると望ましいが先送り可

## 名寄せ
表記ゆれ・言い換えで同一の行動を指すものは1件に統合する。担当や期限が食い違う場合は、より具体的な方を採用し、もう一方を source_quote に追記する。別の行動を誤って統合しない。

## 冪等性
同じ入力からは同じ台帳が出ること。id は task と owner から決定的に採番する。

## コンテキスト方針
- 抽出は会議メモ1本ごとに別エージェント。他のメモを文脈に入れない
- 名寄せ・付与は抽出済みリストと本規約だけを読む
