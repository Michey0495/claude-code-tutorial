# T2 議事録ToDo自動抽出

散らばった会議メモから、担当・期限・優先度つきのタスク台帳を自動で組み立てます。最終成果物は台帳生成CLIと担当者別Markdownビュー。

すべてローカルで完結します。外部送信はありません。企業名・人名はすべて架空です。

## 前提

- Claude Code が使えること
- 学んでおく章: CLAUDE.md / Skills / Subagents / Hooks / 並列化戦略

## 同梱物

```
beta/
├── README.md                 この手順書
├── CLAUDE.md                 台帳スキーマと優先度基準
├── client-brief.md           依頼背景（架空）
├── notes/
│   ├── meeting-01.md         定例会メモ
│   ├── meeting-02.md         顧客打ち合わせメモ
│   └── meeting-03.md         社内レビューメモ
└── .claude/agents/todo-extractor.md   抽出サブエージェント
```

## 進め方

1. 一式を展開し、`CLAUDE.md` の台帳スキーマと優先度基準を確認する
2. 会議メモ3本を `todo-extractor` 3つで同時処理する（並列フェーズ）。各エージェントには担当の1本だけを渡す
3. 抽出ToDoを名寄せして重複を統合する（逐次フェーズ）。ここは抽出済みリストだけを見る
4. 担当・期限・優先度を推定し、台帳スキーマへ正規化する
5. Markdown台帳と担当者別ビューを生成する。Stopフックで件数サマリを自動出力する
6. 同じ入力で再実行し、結果が変わらないこと（冪等）を確かめる

## 受入基準

- メモ3本からToDoを抽出できている
- 重複タスクが統合されている
- 担当・期限・優先度が付いている
- 担当者別ビューが出力される
- 再実行で差分が出ない

## 比較の観点

抽出漏れ / 重複統合精度 / 期限推定の妥当性 / 冪等性。
