# T1 案件健全性ダッシュボード

ヒアリング議事録に埋もれたプロジェクトリスクを抜き出し、深刻度と分類で並べて見えるようにします。最終成果物はリスク可視化Webアプリ（API＋ダッシュボード＋SQLite）。

すべてローカルで完結します。外部送信はありません。企業名・人名はすべて架空です。

## 前提

- Claude Code が使えること（VS Code 拡張 / CLI どちらでも）
- 学んでおく章: CLAUDE.md / Skills / Subagents / 並列化戦略 / Writer-Reviewer

## 同梱物

```
alpha/
├── README.md                 この手順書
├── CLAUDE.md                 プロジェクト規約（リスクの語彙と分類基準）
├── client-brief.md           依頼背景（架空）
├── transcripts/
│   ├── transcript-01.md      PMOヒアリング
│   ├── transcript-02.md      経理ヒアリング
│   └── transcript-03.md      開発リーダーヒアリング
└── .claude/
    ├── agents/risk-extractor.md          抽出サブエージェント
    └── skills/risk-classifier/SKILL.md   分類スキル
```

## 進め方

1. 一式を作業フォルダへ展開し、`client-brief.md` と `CLAUDE.md` に目を通す
2. 議事録3本を `risk-extractor` サブエージェント3つで同時に処理する（並列フェーズ）。各エージェントには担当の1本だけを渡し、他の議事録は見せない
3. 抽出結果を `risk-classifier` スキルで深刻度と分類に判定する（逐次フェーズ）。ここでは抽出時の長い文脈は持ち込まない
4. 判定済みリスクをスキーマへ正規化し、SQLite にシード投入する
5. 一覧とドリルダウンのダッシュボードを実装する。実装役とレビュー役のセッションを分け、Writer/Reviewer で品質を確認する

## 受入基準

- 議事録3本から12件以上のリスクを抽出できている
- 各リスクに深刻度（重大/中/軽）と分類が付いている
- 一覧を深刻度でソートできる
- 詳細から根拠の議事録箇所をたどれる
- この README だけで起動とシード投入を再現できる

## 比較の観点

抽出網羅性 / 分類の妥当性 / UIの可読性 / 根拠の追跡性。同じ入力で別のやり方を試し、上の観点で見比べてください。
