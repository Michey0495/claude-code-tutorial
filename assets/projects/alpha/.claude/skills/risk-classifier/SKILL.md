---
name: risk-classifier
description: 抽出済みリスク候補に深刻度と分類を付ける。議事録本文は再読しない。
---

# 入力
risk-extractor が出したリスク候補のリスト（内容・根拠つき）。

# 判定

## 深刻度
- 重大: スケジュールまたは予算の根幹に影響。放置で計画破綻
- 中: 一部工程の遅延やコスト増。回避策が必要
- 軽: 影響は限定的だが記録は必要

## 分類
スケジュール / スコープ / 品質 / コスト / 体制 から主分類を1つ。
複数該当時は影響の大きい方を主分類、もう一方を備考へ。

# 出力（SQLite シード用）

```
title | severity | category | source_file | source_quote | note
```

# 制約
- 入力リストと本スキルの基準だけで判定する。議事録を再読しない
- 根拠（source_file / source_quote）は入力のものをそのまま引き継ぐ
- 判断に迷う深刻度は1段下げ、note に理由を残す
