## ハンズオン: 外部スキルを探して読み込み、環境で使うまで

### 前提

- Claude Code（CLI または Cursor 等）がインストールされ、利用可能なこと。
- 個人の学習・検証用の環境を推奨（本番・機密環境では特に慎重に判断すること）。

### 手順の流れ

1. **リスク注意を再確認する**
   - 本ドキュメントの「リスクについて（必読）」を読み、利用は自己責任であることを理解する。

2. **サイトでスキル・テンプレートを探す**
   - 上記のいずれかの URL にアクセスし、目的に近いスキルやテンプレートを検索・閲覧する。
   - 例: SkillsMP でカテゴリから「Development」「Tools」などを選ぶ。Awesome-claude-agents の README でエージェント一覧を確認する。

3. **中身を確認してから導入する**
   - 導入前に必ず GitHub リポジトリの SKILL.md（または README）と、同梱されているスクリプト・設定ファイルに目を通す。
   - 不明なコマンド・ネットワークアクセス・ファイル操作が含まれていないか確認する。
   - 導入方法は各リポジトリの README に記載されていることが多い（例: `~/.claude/skills/` や `~/.cursor/skills/` への配置、`npx` コマンドなど）。

4. **ローカルで試す**
   - 可能であれば、本番とは別のディレクトリやプロジェクトで一度動作確認する。
   - Claude Code を起動し、該当スキルが読み込まれているか、意図したとおりにのみ動作するかを確認する。

5. **問題があれば無効化・削除する**
   - スキルを入れたディレクトリから該当フォルダを削除する、または公式ドキュメントに従ってスキルを無効化する。
